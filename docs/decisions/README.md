# Decisions

[`../DESIGN.md`](../DESIGN.md) holds the design and the reasoning behind it, and that is where a
decision lives by default. A decision gets its own file here when it outgrows a paragraph there:
when the alternatives need arguing out, when it will be re-litigated, or when it is superseded
later and both versions have to stay readable.

One file per decision, numbered in the order they are taken, using [`_template.md`](_template.md).
`DESIGN.md` links to it from the section it belongs to, so nothing is reachable only by browsing
this directory.
